# 方法论 · 对标拆解

> 对标不是抄内容,而是理解已验证案例背后的**用户需求、内容结构、成交路径**,借鉴逻辑再做自己的版本。本文件只作方法论与模板,不含任何抓取/采集代码。

## 一、对标三个核心

### 1. 账号对标
- **他是谁**:人设(专业大咖 / 热心学姐)?粉丝是哪类人?
- **发的内容**:主页笔记怎么分类?哪些标题点赞最高?图文还是视频?
- **变现路径**:店内直接卖,还是站外成交(注意平台规则风险)?单价多少?有无会员/课程?
- **成长轨迹**:看他起步阶段的笔记,怎么从无人问津试错变强。

### 2. 笔记对标
优先看【未编辑过】【近期】的【商品笔记】:
- 戳中什么痛点?标题与封面用了哪些词?封面是对比图还是大清单?
- 内容结构:开头如何抓人?中间如何展示价值建立信任?结尾如何引导行动?
- 评论区:用户在问什么?哪些衍生需求未被满足?

### 3. 店铺 / 商品对标
看商品主图、详情页设计、商品名称;定价策略(单卖还是捆绑)?有无优惠券促单?

## 二、什么样的账号值得深入拆
- [ ] 是「活号」:一周稳定更新 3–5 篇,不长期断更。
- [ ] 低粉高爆:粉丝少 / 近期上架新品,但店铺销量高。
- [ ] 自己「搞得定」:能理解、能借鉴、能在合规前提下快速做出自己的版本。

## 三、拆解模板(每拆一个对象填一份)

- **对标对象**:[账号 / 笔记 / 商品名称]
- **1 账号定位**:人设 / 目标人群 / 主要内容类型
- **2 爆款笔记**:标题 / 封面关键词 / 开头钩子 / 内页结构 / 正文引导 / 评论区高频问题
- **3 商品包装**:商品名称 / 价格 / 主图卖点 / 详情页结构 / 交付形式
- **4 可借鉴逻辑**:用户痛点 / 价值展示方式 / 我能优化之处(视觉 / 内容 / 产品 / 服务)
- **5 禁止照搬**:不能复制的标题 / 图片 / 资料 / 详情页

## 四、证据表(看到什么记什么)

> 没看到的写「未获取」,不要用猜的补上。

| 字段 | 说明 |
| --- | --- |
| 拆谁 | 账号或商品 |
| 材料时间 | 什么时候拿到的 |
| 看了什么 | 主页第几篇、几张图、用户给了什么截图/文字 |
| 编号 | E01… |
| 原文/原始数字 | 照抄,`1.2万` 就写 `1.2万`,不要换精确数字 |
| 这条能说明什么 | 事实 |
| 还不确定什么 | 限制 |

**三种话分开写**:
- **事实**:材料里直接看得见的内容。
- **判断**:根据材料做的推测。
- **待验证**:现在还不知道、但可以去试的。三者不要混着写。

**两份材料对不上时**:先问「是不是同一账号 / 同一篇 / 同一种数字 / 同一时间」;分不清就并列写,不要硬选一个「正确答案」。

## 五、复刻 + 优化

先对标拆解,再结合自己的素材和能力做优化(视觉审美、内容清晰度、产品系统性、服务)。**在做的基础上分析可优化点,加入独特价值——这才是优势。**
