# 方法论 · 复盘

> 复盘只解决一件事:把「感觉还行」变成「下一步改什么」。不编数据,没数据先记原因。

## 一、复盘节奏
- 发布后**每 3 天**看一次:点击(曝光/阅读)、收藏、评论、咨询、成交。
- 单次只改**一个主要变量**(标题 / 封面 / 正文 / 商品页),不要同时换多个,否则归因无效。

## 二、指标口径(分开记,别混)
- 点击率看封面 + 标题;收藏看内容价值;评论看互动;咨询看意图;成交看转化。
- **收藏 ≠ 订单**;**咨询 ≠ 成交**;**点击 ≠ 需求**。
- 没有数据时,先记录「为什么没有」(没发布 / 没曝光 / 时间太短),不要立刻判死刑。

## 三、七天闭环 SOP(跑通一次即超越多数空想者)
1. 第 1 天:确定 1 个细分方向,搜索 20 篇相关笔记。
2. 第 2 天:筛选 3 个对标账号、5 个对标商品(优先低粉高销量)。
3. 第 3 天:完成产品 MVP 大纲与资料目录。
4. 第 4 天:制作产品初版与商品页卖点。
5. 第 5 天:设计 3 个封面、5 个标题(套用标题公式)。
6. 第 6 天:发布 3 篇笔记,分别测试不同角度。
7. 第 7 天:复盘数据,优化标题、封面、商品详情与交付内容。

## 四、复盘模板

- **本周期数据**:曝光 / 点击 / 收藏 / 评论 / 咨询 / 成交(逐项,未知写「未获取」)
- **我猜什么**:本次的假设(如「改标题能提点击」)
- **这次只改什么**:一个变量
- **怎么看结果**:看什么反馈、看多久
- **没有结果怎么办**:下一步动作
- **把变量分开记**:点击、收藏、咨询、成交、交付问题分栏记录

## 五、复盘结论的三种写法
- **事实**:数据里直接看得到的。
- **判断**:根据数据做的推测。
- **待验证**:准备下一次测试的想法。
