## 发布前合规检查清单

> 每次发笔记或交付资料前逐项核查。任意一项不通过,先改再发。

- [ ] 资料来源是否清楚?(自己整理 / 自己原创,非搬运)
- [ ] 是否包含机构水印、课程资料、出版物扫描件或未经授权内容?
- [ ] 标题/正文是否夸大效果?(如「保证通过」「月入过万」类表述)
- [ ] 正文是否出现站外联系方式或导流表达?(微信 / 二维码 / 外链)
- [ ] 是否承诺收益、结果、录取、考试通过等不可保证事项?
- [ ] 商品详情是否说明交付形式、适用人群与使用边界?
- [ ] 是否检查过平台违禁词?
- [ ] 是否确认当前类目与资质规则?(以平台官方后台/文档为准)

## 版权三大雷区(坚决不碰)

1. **明确版权归属的内容**:出版物电子版、影音/录播课、知名 IP 衍生品、破解软件。
2. **带显著机构标识的资料**:学校 / 机构 / 出版社 Logo、水印。
3. **有明确版权声明的资源**:标注「未经许可不得复制、传播、销售」的内容。

> 合规是底线:违规不是「赚多赚少」,而是「账号被封、保证金被扣、积累付诸东流」。
