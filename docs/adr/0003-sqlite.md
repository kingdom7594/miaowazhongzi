# ADR-0003:数据层选型 SQLite

- 状态:Accepted
- 日期:2026-10-10

## 背景
miaowazhongzi 原型无持久化(表单→流式输出→复制)。内容工厂需要存:选题库、稿件库、图片引用、发布记录,并支持查询/去重/状态流转。OPC 单人运营,不引入重型数据库运维。

## 决策
数据层选用 **SQLite**(单文件,随应用部署)。

## 后果
- 优点:零运维;单文件易备份/迁移;满足选题/稿件/发布记录的关系查询与事务;与"一人公司"运维成本匹配。
- 代价:并发写能力有限;若未来多用户/高并发需迁移(Postgres)——届时新增 ADR。
- 约束:schema 变更走迁移脚本;数据文件纳入备份。
